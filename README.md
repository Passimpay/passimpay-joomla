# PassimPay for Joomla 5 / JoomShopping 5 / Joomla 3 / JoomShopping 4

Payment modules using PassimPay API v2.

| Module | Version | Source directory | Download | Installation and update |
| --- | --- | --- | --- | --- |
| Joomla 5 / JoomShopping 5 | 1.0.1 | `plg_system_passimpayinstaller` | [passimpay_joomla5.zip](https://cdn1.passimpay.io/upload/passimpay_joomla5.zip) | [Instructions](plg_system_passimpayinstaller/UPGRADE.md) |
| Joomla 3 / JoomShopping 4 | 1.0.1 | `joomla-3x` | [passimpay_joomshopping.zip](https://cdn1.passimpay.io/upload/passimpay_joomshopping.zip) | [Instructions](joomla-3x/UPGRADE.md) |

Use the module ZIP linked above for installation. The GitHub source ZIP contains the repository layout.

Create a platform in your [PassimPay account](https://account.passimpay.io/) to obtain the Platform ID and API Key.
